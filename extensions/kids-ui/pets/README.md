# Rocky artwork

These three immutable images define the shared original Rocky character and its
fixed resting poses. Both children use the same character. Daily normal and
excited scenes remain private, personalized artifacts owned by the activity media
service; they are not additional fixed assets.

- `rocky-reference.webp`: neutral standing reference and normal fallback.
- `rocky-bored.webp`: visibly slouched and seated, cheek resting in one hand.
- `rocky-sleeping.webp`: lying on its side, eyes closed and mouth relaxed.

Rocky is a moss-green rounded mountain creature with an ivory snowy peak, short
rounded arms and feet, and a softly textured clay/felt surface. The reference
owns its identity. Daily generation may change the theme and accessories, but
preserves that identity.

The activity media owner reads these files from the installed plugin directory.
All files have genuine transparent alpha, are at most 720 pixels per side and
512 KiB, and were re-encoded as WebP with metadata stripped. CSS supplies small
motion; these are not animation sprite sheets.

## Generation provenance and prompts

Generated with the built-in image-generation tool. The reference preserves the
top-left neutral pose from the original Rocky concept sheet. Both final resting
poses were generated from that individual reference. The resting poses replace
the earlier subtle-expression previews. The previous two-character artwork is
no longer part of the plugin.

Each request used `transparent_background: true`. The generated PNG alpha was
preserved during WebP conversion and verified on the installed files.
